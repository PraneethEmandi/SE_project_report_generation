# Frontend for the Project

## 📦 Project Info

This repository contains the complete frontend code for the project, built using modern web development tools and frameworks.

## 🛠️ Technologies Used

- [Vite](https://vitejs.dev/) – Lightning-fast frontend tooling
- [TypeScript](https://www.typescriptlang.org/) – Typed JavaScript for better developer experience
- [React](https://reactjs.org/) – Component-based UI library
- [shadcn/ui](https://ui.shadcn.dev/) – Beautifully designed UI components
- [Tailwind CSS](https://tailwindcss.com/) – Utility-first CSS framework

## 💻 How to Run the Project Locally

Make sure you have **Node.js** and **npm** installed. We recommend installing Node via [nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

### Steps:

```bash
# Step 1: Clone the repository
git clone <YOUR_GIT_URL>

# Step 2: Navigate into the project directory
cd <YOUR_PROJECT_NAME>

# Step 3: Install the dependencies
npm install

# Step 4: Start the development server
npm run dev
