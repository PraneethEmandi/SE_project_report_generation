# Spring Boot Backend with JUnit Test Cases

This repository contains the **complete backend code** built using **Spring Boot**. It includes all necessary business logic, service layers, controllers, and integration with a MySQL database.

## ✅ Features
- Full backend implementation using **Spring Boot**
- **15 JUnit test cases** written for unit and integration testing
- Test cases help verify SQL generation, service functionality, and controller behavior

## 🧪 JUnit Test Files
- `GeminiServiceTest.java`: Contains test cases related to Gemini-based SQL generation and validation
- `FullQueryExecutionTest.java`: Includes comprehensive test cases to verify the end-to-end query execution and database interaction

## 📄 Test Case Description
A separate file `TestCaseDescription.docx` is included to provide detailed explanations of each test case:
- Purpose of the test
- Expected input and output
- Dependencies and mocking used

## 🛠️ Technologies Used
- Spring Boot
- JUnit 5
- Mockito
- MySQL
